# 책 옆 한마디 — Vercel 배포용 데모

QR로 접속한 이용자가 책 정보를 보고, 추천/비추천 의견과 댓글을 남겨보는 모바일 웹 프로토타입입니다.

## 1. 가장 쉬운 배포 방법

1. GitHub에서 새 Repository를 만듭니다.
2. 이 폴더 안의 `index.html`, `style.css`, `script.js`, `vercel.json`을 업로드합니다.
3. Vercel에 로그인합니다.
4. **Add New → Project → GitHub 저장소 선택**
5. Framework Preset은 `Other` 그대로 두고 **Deploy**를 누릅니다.
6. 잠시 후 `https://프로젝트이름.vercel.app` 주소가 생깁니다.
7. 그 주소로 QR을 만들면 휴대폰에서 바로 테스트할 수 있습니다.

## 현재 데모에서 되는 것

- 책 표지/기본 정보 표시
- 인터넷서점 링크 이동
- 추천 / 아쉬워요 선택
- 한 줄 의견 작성
- 의견이 말풍선처럼 화면 상단에 추가
- 공감 버튼
- 댓글 열기 및 댓글 작성

## 꼭 알아둘 점

현재는 **프론트엔드 데모**라 새로고침하면 새로 쓴 의견과 댓글이 사라집니다.

실제 도서관 운영 버전에서는 다음 단계로 Supabase 같은 DB를 연결하면 됩니다.

- 의견 영구 저장
- 댓글 영구 저장
- 책별 QR / ISBN별 페이지
- 관리자 삭제
- 신고 기능
- 금칙어 필터
- 여러 권의 책 운영
